# AQSA7 / ALSSAEDY CLINIC v1.4.0

## Release summary

v1.4.0 packages the accepted **AQSA7 Platform-first** source state from Phase 7. The Dental Clinic remains the first configured product while the application shell now presents AQSA7 as the platform.

### User-visible hierarchy

**AQSA7 Platform → Products / Projects → Dental Clinic → ALSSAEDY CLINIC workspace**

### Included

- AQSA7 Platform Home and workspace navigation.
- Products / Projects as a first-class platform surface.
- Dental Clinic as a configured product rather than the platform shell itself.
- ALSSAEDY CLINIC as the active dental workspace/instance.
- Existing receipt, patient, history, settings, backup/recovery, export/print/share and Android functionality preserved through their authoritative owners.
- Phase 7.5 rendered UI acceptance correction for Desktop stacking/navigation layering.
- Documentation aligned to the multi-product platform architecture.

### Android release

- versionName: **1.4.0**
- versionCode: **19**
- Production APK: signed in CI using repository release secrets.
- SHA256 checksum: generated by the release workflow.

### Release verification gate

The release candidate must pass the existing:

- AQSA7 Runtime Smoke
- Android production build + signature verification + metadata verification
- GitHub Pages Source Verification
- Receipt image export verification

### Known limitations

- Live Google production OAuth upload/download/restore requires an authorized production OAuth client/account and is not covered by CI.
- Live-device Android back/share/print interaction requires a connected/emulated Android runtime and is not claimed by the automated gate.

The previous **v1.3.0** release remains the historical artifact and is not modified by this release.
