# AQSA7 / ALSSAEDY CLINIC v1.4.1

## Release summary

This corrective Android release packages the current AQSA7 / ALSSAEDY CLINIC source state and increments the Android version so it is recognised as an update over v1.4.0.

### Android release metadata

- versionName: **1.4.1**
- versionCode: **20**
- Application ID: **com.alssaedy.clinic**
- Production APK: built in GitHub Actions with the configured production signing key.
- APK signature and package/version metadata: verified in the release workflow.
- SHA256 checksum: generated from the exact APK published with this release.

### Included

- Current AQSA7 platform-first home and product navigation.
- Current Dental Clinic workspace and receipt, patient, history, settings, backup/recovery, export/print/share functionality from the repository source.
- Bundled web assets verified as packaged under `assets/web/` in the APK.
- Release workflow checks for the expected package ID, versionCode, versionName, and APK signature.

### Update guidance

Install this APK over the existing app; do not uninstall the existing app first. Android requires a matching application ID and signing certificate, and the new versionCode must be higher than the installed one. Keep the existing app/data until the update is confirmed on the device.

### Known limits

- Automated CI validates the build, signature, and APK metadata; it does not prove the update was installed on a physical phone or that the screen rendered correctly on that device.
- Live Google production OAuth and connected-device print/share flows require their respective authorized accounts/device testing.
